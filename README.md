###  [OBIS Marine Species Classification](https://github.com/sanrajagopal/DSC232RGroupProject)

**Tech:** PySpark, Python, scikit-learn, pandas, seaborn

**My role:** Co-developed the full pipeline (data cleaning, feature engineering, modeling) and co-authored the write-up.
